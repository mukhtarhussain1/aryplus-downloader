# ARY Plus Downloader

A local web application for downloading accessible ARY Plus VOD episodes for offline personal viewing.

## Architecture

1. **Resolver**: Uses Playwright to dynamically intercept backend API requests (specifically searching for `.m3u8` master playlists) generated by the ARY Plus React SPA.
2. **HLS Parser**: Fetches the master playlist and detects available stream qualities (1080p, 720p, etc.).
3. **Download Manager**: Uses `fluent-ffmpeg` / raw `child_process` to spawn FFmpeg. It downloads the HLS stream via a stream copy (`-c copy`), keeping generation fast and lossless.
4. **Frontend**: Next.js App Router API combined with a React interface.

## Requirements

- Node.js 20+
- FFmpeg & ffprobe

## Installation

```bash
# 1. Install Node modules
npm install

# 2. Install Playwright browsers (Required for the resolver)
npx playwright install chromium

# 3. Ensure FFmpeg is installed
brew install ffmpeg
```

## Environment Variables

Copy `.env.example` to `.env`.

```env
PORT=3000
DEBUG_MEDIA_RESOLUTION=false
DOWNLOAD_DIR=./downloads
MAX_DOWNLOAD_SIZE_MB=5000
MAX_CONCURRENT_DOWNLOADS=2
DOWNLOAD_TIMEOUT_MS=3600000
ALLOWED_PAGE_DOMAIN=aryplus.tv
ALLOWED_MEDIA_DOMAINS=vod.aryzap.com
```

## Running Locally

```bash
# Development
npm run dev

# Production
npm run build
npm start
```

## Troubleshooting

- **No streams found**: ARY may have changed their video CDN or player architecture. Check `DEBUG_MEDIA_RESOLUTION=true` logs to observe intercepted Playwright requests.
- **FFmpeg errors**: Ensure `ffmpeg` is available in your PATH.

## Security Considerations

- The application uses domain allowlisting (`ALLOWED_PAGE_DOMAIN`, `ALLOWED_MEDIA_DOMAINS`) to prevent arbitrary SSRF via the resolver or FFmpeg.
- Child processes use array-based arguments rather than shell strings to prevent command injection.
- Temporary files are stored in a designated local directory.

## Legal/Usage Note

This tool is strictly for personal offline viewing of *publicly accessible* and *authorized* media streams. It does NOT bypass DRM, decrypt Widevine/PlayReady, or perform authentication-stealing. It operates solely on unencrypted HTTP Live Streaming (HLS) VOD content.
